# یادداشت انتشار نسخهٔ ۱.۰.۳۰ (`v1.0.30`)

این نسخه با تأیید مالک **بدون امضای فایل به‌روزرسانی** منتشر می‌شود؛ بنابراین
اصالت `latest.json` با امضای دیجیتال قابل تأیید نیست. مجوز انتشار بدون امضا
صرفاً برای همین نسخه است.

## رفع علت احتمالی خطای ورود با موبایل در شبکهٔ محلی

در برخی مرورگرها، وقتی برنامه با آدرس HTTP شبکه مثل `http://192.168.1.20:8787`
باز می‌شود، تابع ساخت شناسهٔ درخواست در دسترس نیست؛ در نسخهٔ قبل این موضوع
می‌توانست پیش از ارسال درخواست ورود به خطای غیرمنتظره منجر شود. برنامه حالا
در این وضعیت از تصادفی‌ساز امن مرورگر برای تولید شناسهٔ درخواست استفاده می‌کند؛
این اصلاح برای سایر درخواست‌های ثبت و تکمیل تطبیق بانکی نیز اعمال شده است.

آزمون ورود با شبیه‌سازی محدودیت مرورگر و آزمون‌های سازگاری انجام شده‌اند؛ امکان
آزمایش مستقیم روی گوشی مالک در این محیط وجود ندارد. اگر پس از نصب و باز کردن
مجدد صفحه هنوز خطایی دیده شد، شبکه و جزئیات خطا باید بررسی شوند.

**امنیت شبکه:** HTTP رمز عبور و اطلاعات نشست را رمزگذاری نمی‌کند. فقط در شبکهٔ
خصوصی و مورد اعتماد از آن استفاده کنید و درگاه برنامه را روی اینترنت باز نکنید.
