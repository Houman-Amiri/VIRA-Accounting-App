1. محلی: ۲۶۷ تست بک‌اند، ۱۱۴ تست فرانت‌اند، ruff، mypy، bandit، قالب‌بندی، lint،
   TypeScript و build موفق. آزمون‌های ابزارهای انتشار نیز جداگانه موفق شدند.
2. [ساخت آزمایشی نهایی پیش از تگ](https://github.com/Houman-Amiri/VIRA-Accounting-App/actions/runs/38826913346)
   روی همان کامیت تگ: هر شش job موفق.
3. [اجرای تگ و انتشار](https://github.com/Houman-Amiri/VIRA-Accounting-App/actions/runs/38828871098):
   هر شش job موفق؛ شامل آزمون‌های Linux، native Windows، قرارداد OpenAPI و پنج
   سناریوی Playwright و ساخت/انتشار بسته‌ها.
4. هر سه delta واقعی با استخراج‌کنندهٔ برنامه اعتبارسنجی و با helper ویندوز روی
   payload پایهٔ متناظر اعمال شدند. الزام اجرای هر سه پایه در smoke فعال است؛
   ردشدن بی‌صدای یک پایه، اجرای موفق محسوب نمی‌شود.
5. checksum و دادهٔ شاهد SQLite پس از ارتقا و شکست اجباری بررسی شد؛ راه‌اندازی
   مجدد، پوشهٔ نصب دارای فاصله، میان‌برها، اجرای تازه و migration تا
   `0005_pricing_settings` نیز بررسی شدند. تست migration بک‌اند حفظ کاربر و JSON
   سفارش واقعی را در رفت‌وبرگشت ۰۰۰۴/۰۰۰۵ کنترل می‌کند.
6. محتوای نصب‌شده با شناسهٔ ساخت، `Cache-Control: no-store`، SHA-256 فایل JavaScript
   سرو‌شده در برابر payload، markerهای ویژگی‌ها و API عملیاتی کنترل شد.
