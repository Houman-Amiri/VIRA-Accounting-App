# اعداد با وزیرمتن — تغییر تکمیلیِ منتشرنشده

**تاریخ:** ۲۰۲۶-۱۰-۱۷  
**درخواست:** همهٔ اعداد برنامه با فونت وزیرمتن نمایش داده شوند.

## تغییرات

- متن و اعداد، از جمله ورودی‌ها، جدول‌ها، تاریخ‌ها، مبالغ و اعداد فنیِ صفحهٔ سیستم،
  از خانوادهٔ مشترک **Vazirmatn** استفاده می‌کنند. فونت جداگانهٔ JetBrains از import
  و وابستگی/lock حذف شد؛ حتی utility قدیمی `font-mono` نیز به همان خانواده نگاشت می‌شود.
- برچسب و tooltip نمودارها صریحاً وزیرمتن دارند. نمودار تراز آزمایشی نیز از renderer
  مشترک SVG استفاده می‌کند. در آزمون واقعی مشخص شد صفحهٔ قدیمی پاسخ لیستیِ API را
  به‌اشتباه `{rows: ...}` می‌پنداشت؛ cast نادرست حذف شد تا ردیف‌ها و نمودار واقعاً
  بارگذاری شوند. پاسخ و محاسبهٔ API عوض نشد.
- قالب پیش‌فاکتور به وزیرمتن تغییر کرد؛ فونت‌های کامل Regular/Bold نسخهٔ ثابت
  `v33.003` از مخزن رسمی، همراه مجوز **SIL OFL 1.1** و SHA-256، محلی بسته‌بندی شدند.
  بنابراین قالب برای یافتن فونت به نصب سیستم‌عامل یا اینترنت وابسته نیست.
- `tabular-nums`، جهت LTR ایزوله، شکل ارقام، جداکننده‌ها، دقت Decimal و فرمول‌ها
  حفظ شدند. فایل دیتابیس کاربر، schema، نسخه و تگ‌ها تغییر نکردند.
- سیاست جدید در هر دو سند اصلی و برنامهٔ فاز تکمیلی ثبت شد؛ گزارش‌های تاریخی
  که سیاست قدیمی را شرح می‌دهند بازنویسی نشدند.

## شواهد محلی

| بررسی | نتیجه |
|---|---|
| Backend کامل | **۳۳۸ تست موفق** |
| Frontend کامل | **۱۸۹ تست موفق** در ۲۷ فایل |
| مرورگر واقعی، پایگاه تازه و دورریختنی | **هر ۵ سناریو موفق** |
| بارگذاری واقعی فونت | حداقل دو FontFace بارگذاری‌شده برای ارقام لاتین و فارسی/عربی؛ نه صرفاً نام فونت در CSS |
| پوشش رابط | داشبورد، قیمت‌گذاری، سند جدید، سفارش، تولید، انبار، ورود بانک، تنظیمات، تراز آزمایشی و صفحهٔ سیستم پس از احراز هویت مجدد؛ هر دو تم |
| کنترل نمایش | فونت محاسبه‌شدهٔ ورودی‌ها، اعداد و متن SVG؛ tooltip واقعی؛ حفظ tabular و LTR/isolate؛ قیمت‌گذاری دسکتاپ/موبایل و تعداد ۱ و ۱۰ |
| فونت پیش‌فاکتور | هویت خانواده، هش و وجود glyphهای `0123456789`، `۰۱۲۳۴۵۶۷۸۹` و `٠١٢٣٤٥٦٧٨٩` در هر دو TTF؛ HTML و مقدار دقیق خروجی |
| کنترل کیفیت | TypeScript، ESLint، Ruff، mypy، production build و `git diff --check` موفق |

آزمون‌های فونت ابتدا با سیاست قدیمی قرمز شدند و پس از اصلاح سبز شدند. در توسعهٔ
آزمون مرورگر، حالت بدون عددِ صفحهٔ ورود بانک و گزارش بدون ورودی نیز به‌درستی
تفکیک شدند؛ assertion فونت حذف نشد. ورود به صفحهٔ سیستم با step-up واقعی انجام
می‌شود و کنترل امنیتی دور زده نشده است. اجرای چندباره روی DB قبلی، fixtureهای
هشدار را انباشته کرد و assertion سه هشدار اول را شکست؛ اجرای کامل نهایی روی DB
تازه، بدون تغییر محدودیت ورود یا منطق هشدار، هر پنج سناریو را پاس کرد.

**CI:** پس از ثبت کد اجرا می‌شود؛ نتیجهٔ دوردست هنوز در این نسخهٔ اولیهٔ گزارش
تأیید نشده است.

## مرز تأیید

- این محیط کتابخانه‌های native موردنیاز Pango/Cairo را ندارد؛ **رندر واقعی PDF و
  مشاهدهٔ فونت جاسازی‌شده در PDF اینجا تأیید نشده است**. تست HTML و فایل/glyph
  فونت، جای تأیید PDF native یا مشاهدهٔ ویندوز نصب‌شده را نمی‌گیرد.
- پذیرش دیداریِ نصب واقعی و تست دادهٔ کسب‌وکار طبق خواستهٔ کاربر تا پایان کار
  باقی می‌ماند. این گزارش ادعای تأیید آن‌ها نیست.
- **هیچ نسخه/installer/به‌روزرسانی عمومی تازه منتشر نشده است.** شمارهٔ برنامه
  همچنان ۱.۰.۱۰ است؛ این تغییر برای بستهٔ بعدی نگه‌داری می‌شود.
- پیاده‌سازی نوع/واحد/تأمین‌کنندهٔ قابل‌مدیریت در تنظیمات، مرحلهٔ مستقل بعدی است؛
  گیت موفقِ rollback قبلی جای آزمون migration نهایی آن مرحله را نمی‌گیرد.
