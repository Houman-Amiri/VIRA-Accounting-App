# ساخت مستقل native PDF و شواهد کامپایلر/CRT

تاریخ: ۲۰۲۶-۱۰-۱۸ — گام آماده‌سازی، نه انتشار یا اتصال موتور به نصب عادی.

## تغییر انجام‌شده

ورودی جدید `scripts/rebuild_pdf_native.ps1` از سایدکار محدودِ دارای MIT اجرا
می‌شود؛ برای کامپایل native به checkout برنامه، backend/frontend، Node، pnpm،
uv، محیط Python برنامه، staging، Inno یا دیتابیس احتیاج ندارد. Windows x64،
PowerShell 7، Git، کامپایلر/SDK با شرایط مجاز و اینترنت لازم‌اند؛ این SDK آفلاین
نیست. ابزارهای bootstrap دانلودشده، سورس‌ساخت معرفی نشده‌اند.

[راهنمای دریافت، plan، ساخت و overlay](../dependencies/pdf-native-rebuild-guide.md)
دستورهای قابل اجرا را دارد. مسیر ساخت باید جدید و مطلق باشد؛ حتی plan مسیر موجود
را رد می‌کند. cache باینری در محیط و خط فرمان خاموش است؛ vcpkg پین‌شده و triplet
هدفِ DLL با CRT استاتیک/release و host با CRT پویا استفاده می‌شوند. ابزار هیچ مسیر
نصب/داده‌ای را پاک یا بازاستفاده نمی‌کند. marker عدم توزیع، وضعیت آمادگی پروژه است،
نه شرط اضافه بر MIT.

دو فایل جدیدِ driver و native audit، مشتقات ابزار ساخت مجازند و صریحاً به دامنه
اضافه شده‌اند: اکنون ۱۱ فایل، نه MIT سراسری. متن مجوز، هش‌ها و ۷ تطبیق تاریخی با
آرشیو اصلی کنترل می‌شوند؛ ZIP و notices قبلی تغییر نکرده‌اند. دستور قدیمیِ متکی
به staging برنامه همچنان ورودی مستقل محسوب نمی‌شود.

## اثبات واقعی، جدا از تست قرارداد

[اجرای مستقل 39108011284](https://github.com/Houman-Amiri/VIRA-Accounting-App/actions/runs/39108011284)
روی `d5b2516` سایدکار را خارج از checkout صادر و plan/رد مسیر موجود را اجرا کرده
است. نتیجهٔ نهایی کامپایل و ممیزی باید با
[proof ماشین‌خوان](../dependencies/pdf-native-rebuild-proof-run.json) تطبیق داده شود؛
تا وقتی وضعیت اجرای طولانی `IN_PROGRESS` است، ادعای موفقیت بازسازی نداریم.

ممیزی جداگانه، Python/pefile می‌خواهد؛ این وابستگیِ بازرس است، نه کامپایل. معیارها:
برابری درخت preferred source بیست بسته، مالک و closure بیست‌ویک DLL و بارگذاری واقعی
همگی از مسیر خروجی خصوصی. تغییر سورس مجاز می‌تواند هش مرجع را عوض کند؛ شکست در
مقایسه با baseline ممنوعیت تغییر MIT/LGPL نیست. تست قرارداد یا اجرای plan جای
کامپایل/بارگذاری واقعی را نمی‌گیرد. موفقیت native نیز به معنی PDF برنامه با همین
خروجی جدید یا بازتولید بیت‌به‌بیت نیست.

## کامپایلر واقعی، نه نسخهٔ Python

۱۵ قطعهٔ کاملِ metadata بازیابی و ۱۶ رکورد واقعیِ تشخیص کامپایلر اصلی ثبت شد:

- MSVC `19.51.36260.0`؛ مسیر Visual Studio **18 Enterprise**، toolset **v145**؛
- مسیر ابزار `14.51.36231`؛ SDK/rc برابر `10.0.26100.0`؛
- تنظیمات CRT هدف static و host dynamic در CMakeCache اصلی مشخص‌اند.

[رکوردها و هش فایل‌های اصلی](../dependencies/pdf-native-original-compiler-evidence.json)
از artifact ساخت اصلی خوانده شدند؛ نسخهٔ `MSC 1944` مربوط به ساخت Python همراه
بود و مدرک نسخهٔ کامپایلر این کتابخانه‌ها نیست. snapshot فعلی runner از شواهد
تاریخی تفکیک شده است. excerpt هر رکورد حداکثر ۳۰ خط و هر خط ۱۲۰۰ کاراکتر است؛
پرچم `lines_truncated` فقط سقف تعداد خط را گزارش می‌کند، نه کوتاه‌شدن عرض هر خط.
بنابراین false بودن آن به معنی کامل‌بودن متن همهٔ خط‌ها نیست؛ هش، متعلق به فایل
اصلی کامل است و نسخهٔ اصلی در artifact تاریخی باقی است.

## متن‌های واقعی مجوز و مرز نتیجه‌گیری

اجرای موفق [39108554105](https://github.com/Houman-Amiri/VIRA-Accounting-App/actions/runs/39108554105)
۱۰ سند انگلیسیِ نصب‌شده را بررسی کرده است؛ چهار قطعهٔ metadata کامل، هش bytes اصلی
و هش متن استخراج‌شده داریم. RTF با RichTextBox ویندوز به متن تبدیل شد؛ متن کامل
در artifact بررسی ۹۰روزه و preview محدود در
[شواهد نصب‌شده](../dependencies/pdf-native-installed-terms-evidence.json) است.
این اسکن EULA اصلی VS را پیدا نکرد؛ ThirdPartyNotices یا REDIST فقط ۱۹۰بایتی،
به‌اشتباه مجوز کامل MSVC معرفی نشدند. شکست نخستِ انتقال metadata نیز ثبت و با
انتقال محدودِ metadata/نگهداری متن کامل در artifact اصلاح شد.

سپس از فهرست رسمی مایکروسافت، **متن واقعی توافق‌های ۲۰۲۶** برای Enterprise/
Professional، Build Tools و C++ Runtime و فهرست REDIST پیدا و خوانده شد؛
[نشانی، بندهای بررسی‌شده و نتیجهٔ محدود](../dependencies/pdf-crt-official-reference-review.json):

- نصب Enterprise روی runner، به‌تنهایی اثبات entitlement تولیدکننده نیست؛ حقوق
  trial و full-use متفاوت‌اند و بند II.7 توزیع full-use شروط جدا دارد.
- استثنای ساخت وابستگی‌های متن‌باز در Build Tools بند 1(d) وجود دارد؛ بند 1(e)
  محدودیت جدا برای توسعه/تغییر دارد. این را مجوز بی‌قید توزیع یا تغییر دلخواه LGPL
  با همان کامپایلر معرفی نکرده‌ایم.
- اجازهٔ نصب/استفاده از C++ Runtime، اجازهٔ بازتوزیع آن نیست؛ بند 4 محدودیت جدا دارد.
- فهرست DLLهای REDIST، به‌تنهایی تطبیق اجزای CRT استاتیک را اثبات نمی‌کند. SDK
  نصب‌شده متن واقعی مربوط به linked .lib و شروط توزیع دارد؛ snapshot فعلی، bytes
  تاریخیِ نصب اولیه معرفی نشده است.

منابع رسمی به‌صورت متن parse‌شده خوانده شده‌اند؛ هش فایل خام DOCX دوردست ادعا
نشده است. محصول‌کلید، رمز یا credential از مالک خواسته/ذخیره نشده است. حقوق واقعی
کامپایلر و تطبیق اجزای CRT هنوز بازند؛ این گزارش تأیید حقوقی یا مجوز انتشار نیست.

## آزمون‌ها و شکست‌هایی که نباید پنهان شوند

۱۳ تست قرارداد مستقل + تست‌های scope؛ با اصلاح diagnostic، **۴۷۶ تست بک‌اند محلی**،
Ruff و Mypy روی ۸۴ فایل موفق‌اند. نتایج اجرای عادی ویندوز/فرانت‌اند/مرورگر در proof
ثبت می‌شوند؛ صرف موفقیت تست‌های محلی یا چهار job به‌عنوان موفقیت هر پنج job گزارش
نمی‌شود.

اجرای عادی `39108554186` واقعاً در fixture به‌روزرسانی ویندوز شکست خورد: هدف به
readiness/build validation نرسید و rollback تأیید شد. سپس stdout قدیمی cp1252
هنگام نمایش متن Unicode قطع شد و علتِ startup را پوشاند. اصلاح فقط در harness
است: annotation با escape صریح ASCII به گزارش همهٔ logها ادامه می‌دهد؛ شرط سلامت،
hash، rollback یا کد تولید ضعیف نشده است. تست رگرسیون UTF-8/CRLF/cp1252 افزوده شد؛
اجرای اولِ همین تست روی Windows، تبدیل دوبارهٔ CRLF در fixture را نشان داد و با
نوشتن bytes دقیق اصلاح شد. علت readiness بدون شواهد جدید حدس زده نشده است.

## گیت‌های باز و کارهای انجام‌نشده

وضعیت توزیع همچنان **BLOCKED_PENDING_LICENSE_AND_CORRESPONDING_SOURCE_REVIEW** است.
بررسی اجزا/مجوزها، entitlement و CRT استاتیک، بستهٔ کامل source/recipe تحویلی، تحویل
پایدار و قابل دانلود به دریافت‌کننده، جایگزینی سازگار LGPL/EULA، bootstrap عمومی
Unicode/font، نصب تمیز و native delta/rollback و پذیرش نصب‌شده جدا هستند. artifact
۹۰روزه، تحویل پایدار سورس نیست. اثبات baseline، اثبات همهٔ تغییرات احتمالی کتابخانه
یا همهٔ محیط‌های کامپایل نیست.

هیچ DLL به payload معمول اضافه نشده؛ نسخه/تگ/Release یا نصب مجدد نداریم. برنامه،
دیتابیس واقعی، رسیدها، محاسبات مالی و مقادیر قیمت‌گذاری دست‌نخورده‌اند. آزمایش
کسب‌وکار روی نصب مالک مطابق درخواست قبلی به بعد موکول است، نه موفق فرض شده است.
